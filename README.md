# 💰 Учёт финансов

Личный трекер расходов, доходов и планов в **одном HTML-файле**. Без установки, без сервера, без регистрации — открыл файл и ведёшь учёт.

## 🛡 Безопасность и приватность

- **Все данные хранятся только на вашем устройстве** — в `localStorage` браузера. Ни один байт не отправляется в интернет: ни аналитики, ни рекламы, ни серверов.
- Приложение — один статический HTML-файл. Можно проверить весь код руками: никакого сборщика, фреймворков и телеметрии нет.
- Файл можно открыть локально (двойным кликом) или выложить на свой GitHub Pages — данные всё равно остаются у вас.
- **Единственный риск** — потеря данных при очистке браузера. Поэтому: регулярно скачивайте бэкап («Настройки → 📁 Данные → Скачать бэкап», файл `.json`). Восстановление — кнопкой рядом, всё возвращается целиком.

## ✨ Возможности

**✏️ Внести** — быстрая форма для расходов и доходов (дата, сумма, категория, подкатегория, статья, источник). История последних записей — рядом.

**🎯 Планы** — бюджеты на период (даты «от — до», сумма, источник дохода):

- статус плана считается **автоматически по числу фактических платежей** в периоде: 1–2 платежа — «разовый» (достиг лимита → «✅ выполнено» и уходит в завершённые), 3 и более — «потоковый» (бензин, еда, транспорт: живёт в активных до даты окончания, при превышении показывает «перерасход +X»);
- порог «потоковости» — константа `STREAM_MIN = 3` в начале скрипта, меняется одной цифрой;
- активные планы отсортированы по заполнению: сверху — самые затраченные и перерасходные, внизу — нулевые (по убыванию суммы плана);
- прогресс-бар заливается цветом категории, процент в строке всегда честный — даже если это 125% или 663%.

**📊 Обзор** — сводка за период:

- «🛡 Запас прочности» — свободные деньги минус остаток по активным планам;
- «🤖 Помощник» — текстовая расшифровка состояния учёта по-человечески;
- траты по категориям (за период и за всё время), «конверты» по источникам дохода.

**⚙️ Настройки** — счета, источники дохода, категории; тёмная тема; бэкап/восстановление (JSON); импорт истории из CSV; единый экспорт всего учёта в один `учёт.csv` (ТИП / ДАТА / ДАТА КОНЦА / СУММА / КАТЕГОРИЯ / ПОДКАТЕГОРИЯ / СТАТЬЯ / ИСТОЧНИК / КОММЕНТАРИЙ, где ТИП = РАСХОД / ДОХОД / ПЛАН).

## 🚀 Быстрый старт

1. Скачайте `index.html` из репозитория.
2. Откройте его в браузере (двойной клик) — либо разместите в своём репозитории GitHub Pages.
3. Вручную или через CSV импортируйте историю. Формат CSV (разделитель `;`):

```
Расходы:  Дата;Сумма;Категория;Подкатегория;Статья
Доходы:   Дата;Сумма;Источник;Описание
Планы:    Категория;Начало;Конец;План;Источник;Подкатегория;Комментарий;Постоянный;Дата платежа
```

Даты — `DD.MM.YYYY`. Десятичный разделитель не важен, кодировка — UTF-8 (с BOM тоже понимается).

4. Первым делом сделайте бэкап 🙂

## ❓ FAQ

**Данные пропали после очистки браузера / смены устройства?** Восстановите из `.json`-бэкапа. Автооблачной синхронизации нет и не планируется — это принципиально: приватность дороже удобства.

**Что если поменять `STREAM_MIN`?** Меньше 3 — больше планов считаются «потоковыми» (не закрываются досрочно), больше 3 — больше планов ведут себя как разовые (кредиты, ЖКХ).

**Можно вести два учёта (например, два устройства)?** Учёт живёт в `localStorage` конкретного браузера. Для переноса — экспорт CSV или перенос JSON-бэкапа.
